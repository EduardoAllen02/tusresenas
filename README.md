# TusReseñas — vitrina

Sitio de TusReseñas publicado como demostración en GitHub Pages:
**https://eduardoallen02.github.io/tusresenas/**

Este repositorio contiene **únicamente el sitio ya compilado** (HTML, CSS,
JavaScript e imágenes). El código fuente vive aparte y no se publica aquí.

## Qué funciona y qué no

GitHub Pages sirve archivos estáticos, sin servidor detrás. Por eso, en esta
versión:

- Se puede navegar todo el sitio: inicio, plataforma, placas, respuestas con
  IA, encuestas, planes, comparativa, las siete industrias y los legales.
- La calculadora de placas **sí** calcula precios y volúmenes reales.
- Los formularios **no** envían nada y el pago **no** se procesa: ambos
  muestran los datos de contacto en su lugar. Eso necesita el servidor.

El sitio está marcado con `noindex` a propósito: es una copia de demostración
y no debe competir en buscadores con el dominio definitivo.
